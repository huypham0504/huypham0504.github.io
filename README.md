# Pham Quoc Huy — Portfolio

Personal portfolio of **Pham Quoc Huy**, Finance & Banking Law graduate (University of Economics and Law, VNU-HCM), seeking a Legal Assistant role.

Live: https://huypham0504.github.io

Built with Next.js 15, MDX, Velite and shadcn/ui, statically exported and deployed to GitHub Pages.

## Development

```bash
corepack enable
yarn install
yarn dev
```

## Content

```
content/
├── projects/   # One folder per item: <slug>/index.mdx (EN) + index.vi.mdx (VI) + cover image
└── blogs/      # Blog posts
src/config/     # Name, links, experience, skills, resume, services, navbar
public/
└── pham-quoc-huy-cv.pdf   # File opened by the "Download PDF" button on /cv
```

See [HUONG-DAN.md](HUONG-DAN.md) for a Vietnamese step-by-step guide.
